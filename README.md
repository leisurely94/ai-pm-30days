# AI 产品经理 30 天课程表

一份面向转型 AI 产品经理的 30 天自学计划，按 6 个阶段推进：AI PM 角色认知 → 产品思维筑基 → 大模型技术理解 → 设计·评测·指标 → 作品集实战 → 面试投递。

每天包含：1 个学习主题、3 个公开可访问的学习链接（文章 / 官方文档 / B 站视频）、1 项必须交付的产出任务。

## 在线查看

开启 GitHub Pages 后可直接访问：`https://<你的用户名>.github.io/ai-pm-30days/`

## 本地查看

下载 `index.html`，用浏览器打开即可，无需任何依赖。

## 适合谁

- 有技术背景、想转 AI 产品经理的工程师
- 需要一套可执行、有产出的自学习路径，而不是零散收藏
